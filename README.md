#  YouTalk Blog — Адаптивная вёрстка

Вёрстка двухстраничного блога о психологии по макету из Figma.  

## 🛠 Технологии
- **HTML5**: семантические теги (`<header>`, `<main>`, `<footer>`, `<article>`, `<aside>`, `<nav>`);
- **CSS3**: Grid, Flexbox, кастомные свойства, медиа-запросы, псевдоэлементы/псевдоклассы;
- **Методология БЭМ** для именования классов;
- **Графика**: SVG-иконки + PNG-изображения с `alt` и `loading="lazy"`;
- **a11y**: ARIA-метки, класс `.visually-hidden`, стили `:focus-visible`, контрастные цвета.

##  Структура проекта
```
youtalk-blog/
├── index.html          # Главная: список статей, фильтры, футер
├── article.html        # Страница статьи с боковым сайдбаром
├── css/
│   └── style.css       # Базовые стили + адаптив (3 брейкпоинта)
├── images/             # PNG-картинки статей и иллюстраций
└── icons/              # SVG: логотип, соцсети, декоративные элементы
```
